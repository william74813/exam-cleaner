# v2.2 統一 AI 去筆跡 Proxy 契約

## 目的

GitHub Pages 前端不得內建共用 Gemini API Key。前端只呼叫安全 Proxy，由 Proxy 驗證來源、限制請求大小、加入固定提示詞並呼叫影像編輯模型。

## Endpoint

`POST /api/clean`

### Request

```json
{
  "version": "exam-clean-v1",
  "image": {
    "mimeType": "image/jpeg",
    "data": "BASE64_IMAGE_DATA"
  },
  "options": {
    "removeAllAddedMarks": true,
    "preservePrintedContent": true,
    "preserveLayout": true,
    "outputMimeType": "image/png"
  }
}
```

### Response — success

```json
{
  "requestId": "uuid-or-provider-id",
  "image": {
    "mimeType": "image/png",
    "data": "BASE64_IMAGE_DATA"
  },
  "warnings": []
}
```

### Response — error

```json
{
  "error": "可供使用者理解的錯誤訊息",
  "requestId": "optional-id"
}
```

## 固定提示詞要求

Proxy 應自行加入固定提示詞，前端不得允許使用者改寫核心規則：

1. 保留所有原始印刷題目、說明、文字、數字、標點與頁碼。
2. 保留數學公式、運算符號、單位、答案線、表格、圖片、圖形與 QR Code。
3. 移除所有後來加上的手寫答案、鉛筆字、原子筆字、老師批改、分數、勾叉、圈選與註記。
4. 不區分老師或學生筆跡。
5. 不得解題、補答案、改寫題目、翻譯、重新排版、裁切或新增內容。
6. 被移除區域只能使用周圍原始紙張背景修補。
7. 輸出方向與長寬比應與輸入一致。

## 安全要求

- API Key 只存於伺服器環境變數。
- 驗證 `Origin`，只允許正式網站與明確測試來源。
- 限制 JSON 與 Base64 圖片大小。
- 僅允許 JPEG／PNG／WebP。
- 加入速率限制與每日用量上限。
- 不記錄完整圖片或 Base64 內容。
- 錯誤紀錄只能保留 request ID、時間、狀態碼與耗時。
- 正式環境應設定逾時、重試與供應商錯誤遮罩。

## 前端覆核

即使 Proxy 成功回傳，前端仍必須：

- 檢查長寬比是否明顯改變。
- 檢查解析度是否明顯降低。
- 顯示處理前／後比較。
- 要求使用者人工確認後才能下載或加入 PDF。
