# v2.2 統一 AI 去筆跡 Proxy 契約

## 目的

GitHub Pages 前端不得內建共用 Gemini API Key。前端只呼叫安全 Proxy，由 Proxy 驗證來源、限制請求大小、加入固定提示詞並呼叫影像編輯模型。

核心規則只有一種：**保留原始印刷內容，移除所有後加筆跡**。不區分老師或學生筆跡。

## Endpoint

`POST /api/clean`

### Headers

```http
Content-Type: application/json
X-Exam-Cleaner-Token: OPTIONAL_SESSION_TOKEN
```

`X-Exam-Cleaner-Token` 為可選機制。Proxy 設有 `ACCESS_TOKEN` 時，前端必須提供；權杖只應保留於目前瀏覽器分頁的 `sessionStorage`。

### Request

```json
{
  "version": "exam-clean-v2",
  "clientRequestId": "browser-generated-uuid",
  "image": {
    "mimeType": "image/jpeg",
    "data": "BASE64_IMAGE_DATA",
    "width": 1600,
    "height": 2263
  },
  "options": {
    "removeAllAddedMarks": true,
    "preservePrintedContent": true,
    "preserveLayout": true,
    "outputMimeType": "image/png"
  }
}
```

三個布林保護選項都必須是 `true`，否則 Proxy 應拒絕請求。前端不得提供關閉這些規則的介面。

### Response — success

```json
{
  "requestId": "uuid-or-client-request-id",
  "image": {
    "mimeType": "image/png",
    "data": "BASE64_IMAGE_DATA"
  },
  "warnings": [],
  "meta": {
    "promptVersion": "printed-preservation-v2",
    "model": "gemini-3.1-flash-image",
    "durationMs": 18342,
    "remainingToday": 18
  }
}
```

`remainingToday` 在未啟用伺服器端用量限制時可以是 `null`。

### Response — error

```json
{
  "error": "可供使用者理解的錯誤訊息",
  "requestId": "optional-id"
}
```

建議狀態碼：

- `400`：契約或必要保護選項錯誤
- `401`：存取權杖錯誤
- `403`：來源不允許
- `413`：圖片或 JSON 太大
- `415`：不支援的圖片格式
- `429`：用量或供應商配額已達上限
- `502`：上游 AI 回傳錯誤或沒有圖片
- `504`：處理逾時

## 固定提示詞要求

Proxy 應自行加入固定提示詞，前端不得允許使用者改寫核心規則：

1. 保留所有原始印刷題目、說明、文字、數字、標點與頁碼。
2. 保留數學公式、運算符號、單位、答案線、表格、圖片、圖形、條碼與 QR Code。
3. 保留所有元素的原始位置、比例、間距、方向與頁面版型。
4. 移除所有後來加上的手寫答案、鉛筆字、原子筆字、老師批改、分數、勾叉、圈選、螢光筆與註記。
5. 不區分老師或學生筆跡。
6. 不得解題、補答案、改寫題目、翻譯、重新排版、裁切或新增內容。
7. 被移除區域只能使用周圍原始紙張背景修補。
8. 輸出方向與長寬比應與輸入一致。

## Gemini 呼叫方式

目前 Worker 範例使用：

```text
POST https://generativelanguage.googleapis.com/v1/models/{MODEL}:generateContent
```

請求內容以一個文字 `Part` 加上一個 `inline_data` 圖片 `Part` 組成，並將 `generationConfig.responseModalities` 限制為 `IMAGE`。回傳圖片由 `candidates[].content.parts[].inlineData` 取得，且必須忽略標記為 `thought` 的中間內容。

## 安全要求

- API Key 只存於伺服器環境變數。
- 驗證 `Origin`，只允許正式網站與明確測試來源。
- 正式使用時建議啟用額外 `ACCESS_TOKEN`。
- 限制 JSON、Base64 輸入與輸出大小。
- 僅允許 JPEG／PNG／WebP。
- 加入速率限制與每日用量上限；Worker 範例可選用 Cloudflare KV。
- 不記錄完整圖片、Base64、API Key 或存取權杖。
- 錯誤紀錄只能保留 request ID、時間、狀態碼、模型與耗時。
- 正式環境應設定逾時、至多一次暫時性錯誤重試，以及供應商錯誤遮罩。
- 回應必須設定 `Cache-Control: no-store`。

## 前端自動檢查

即使 Proxy 成功回傳，前端仍必須：

- 檢查長寬比是否明顯改變。
- 檢查解析度是否明顯降低。
- 比較處理前後的印刷文字／線條邊緣保留率。
- 計算全頁像素變動比例。
- 標示高變動區塊，方便逐區人工覆核。
- 高風險結果不得直接下載。
- 顯示處理前／後滑桿比較。
- 要求使用者人工確認後才能下載或加入 PDF。

自動分數只是風險提示，不能取代人工覆核，也不能證明 AI 結果正確。
