# Exam Cleaner Ultimate

免費、可離線使用的考卷掃描、去筆跡與重製工具。

## 目前狀態

- GitHub Pages 已部署
- 現有版本支援圖片匯入、基本去筆跡、PWA 與 AI 設定
- 正式開發將由 v2.1 掃描引擎開始

## 正式網站

https://william74813.github.io/exam-cleaner/

## 開發原則

1. 優先保護學生資料與 API Key。
2. 所有 AI 輸出都必須在列印前人工覆核。
3. 先完成可實際使用的版本，再逐步擴充。
4. 每個版本以 Issue 與 Pull Request 管理。
